# Agent bootstrap

Read [docs/README.md](docs/README.md) before substantial repository work. It is the documentation portal for the maintained architecture and current research state.

Before changing documentation, package ownership, public interfaces, research status, or execution instructions, also read [docs/AGENTS.md](docs/AGENTS.md). That file defines documentation routing, update triggers, retention, and pre-finish checks.

Determine current behavior from the source tree and executable tests, then reconcile the relevant current documentation. Do not treat completed design chronology or Git history as the current runtime contract.

Keep changes scoped. Preserve the documented causality, fit/evaluation separation, execution/accounting authority, risk boundaries, immutable evidence, and research-status distinctions unless the task explicitly changes those contracts and verifies the change.
